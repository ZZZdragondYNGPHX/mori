# 第五批：偷看、日常与工作

本批用内置 `image_gen` 制作，沿用已确认的 `motion-study-v1/sources/head.png` 身份参考。完整生成指令见 [prompts.json](prompts.json)，十张透明原画位于 [sources](sources/)，十二个分享用动画位于 [gifs](gifs/)。

新增十组、每组四张真实姿势：上沿趴着偷看，呼吸眨眼，思考，进食工作，等待招手，成功庆祝，失败安慰，收纳资料，伸懒腰，打盹。完整角色连通轮廓从原画提取，各组统一缩放到 280×230 透明画布；独立的装饰线不作为运行人物轮廓。没有用单张图形变代替新增姿势。

运行素材在 `src/asset_library/motion/`，累计 120 张 PNG 和 57 段动作。前四批 80 张 PNG 未修改，哈希快照见 `approved-png-hashes.json`。九种默认 GIF 均重建为四张真实姿势；触摸与抓起复用前面确认的 head／pickup 姿势，其余七种使用本批新图。替换前九个 GIF 存档于 `original-gifs/move/`，更早的静态 PNG 回退保留兼容。

默认待机、进食、思考、等待、悬空可以循环；庆祝、安慰、收纳、触摸以及伸懒腰／打盹完成后停留在恢复姿态。实际桌宠为关键姿势补充约 120ms、可以中途打断的过渡；GIF 文件保留原始姿势时序。伸懒腰和打盹只在娱乐待机使用，工作事件会结束休息。窗口动作需完整身体和走近时的步态能放进可用屏幕，上沿互动还检查窗口宽度；空间不足则跳过或结束。

从项目根目录重建（需要 Pillow，先保留／构建前四批清单）：

```bash
python scripts/build_life_assets.py
```

只重新导出当前九个默认 GIF：

```bash
python scripts/build_gifs.py
```

查看 [第五批本地预览](../../docs/life-preview.html)，可暂停、逐帧、慢放、切换过渡，试验左右／上沿空间、坐下起身、伸手和工作状态。前四批预览保留各批视觉确认记录。
