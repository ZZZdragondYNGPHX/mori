# 第四批：窗沿互动

通过内置 image_gen 生成 5 张透明 2×2 原画，沿用已确认的角色身份与画风，左右探头各自绘制，尾巴保持原来的身体侧。完整提示词、参考图角色和输出位置记录在 [prompts.json](prompts.json)。

- `sources/`：左右探头、坐下、晃腿、伸手按按钮原画，共 5 张。
- `gifs/`：8 个可分享的动作预览；GIF 为便于比较而重复播放，运行时仅晃腿循环。
- `inspection/`：按完整连通人物提取的 280×230 姿势，供本地检查。
- `approved-batches-hashes.json` / `approved-clips.json`：制作前对已确认前三批的快照。

运行素材位于 `src/asset_library/motion/window-*.png` 和 `clips.json`，构建脚本为 `scripts/build_window_assets.py`。Pillow 只用于构建时的完整人物提取、统一比例缩放与透明 GIF 导出。运行时不调用生图，也不新增依赖。

在 [本地交互预览](../../docs/window-preview.html) 中查看完整坐下／起身剧情、左右探头和伸手触碰。拖动或缩放示意窗口时继续当前动作进度；此页面不操作实际应用窗口。桌宠中的真正最小化仍需启用原有独立设置。

每张姿势保留完整头发、头饰、鞋子和尾巴。站立／屈膝时鞋底对齐窗沿，坐下后手掌与臀部对齐窗沿；改变透明窗口的位置而不裁切原画。探头使用绘制遮挡，隐藏部分不参与部位点击，切回走路时清除遮挡。沿用原有剧情频率和专注模式规则。
